# Vault

PWA de control financiero personal preparada para España.

Incluye acceso con correo, Google y Apple; sesión persistente; ingresos, gastos, cuentas, categorías, objetivos, exportación CSV, PWA y eliminación de cuenta. Los datos se separan por UID y las reglas de Firestore deniegan por defecto el acceso ajeno.

Lee `CONFIGURACION.md` antes de publicar. La interfaz usa español, euros y fechas de España. Los documentos legales son plantillas y requieren revisión profesional.
